# Тестовые сценарии

## Автоматические тесты

1. Проверить, что обязательные SPDD-файлы и промпты существуют.
2. Проверить, что REASONS Canvas содержит все разделы: Requirements, Entities, Approach, Structure, Operations, Norms, Safeguards.
3. Проверить наличие архитектурных пакетов `blueprints`, `controllers`, `services`, `views`, `ui`.
4. Проверить, что список аудиторий из seed-файла читается корректно.
5. Проверить, что окно уведомлений имеет ожидаемую ширину и не ломает компактный режим.
6. Проверить, что двухзначные спинбоксы времени редактируемы вручную.
7. Проверить, что ответ VK-бота `Онлайн занятий в выбранном периоде нет.` останавливает активный запрос расписания.
8. Проверить, что ручной выбор аудиторий возвращает выбранные аудитории, время и описание.
9. Проверить, что автозапись не включается при простом изменении времени без `OK`.
10. Проверить, что недействительный интервал автозаписи отклоняется.
11. Проверить, что полуавтомат записи формирует название в формате `Аудитория ДД_ММ_ГГГГ`.

## Ручные функциональные сценарии

### Сценарий 1. Загрузка расписания через VK-бота

Шаги:

1. Открыть приложение.
2. Авторизоваться в VK Web при необходимости.
3. Запустить запрос расписания на сегодня.
4. Дождаться ответа бота.

Ожидаемый результат:

- отправляется ограниченное число сообщений;
- если бот отвечает, что занятий нет, повторные запросы прекращаются;
- в интерфейсе отображается `Занятий нет`.

### Сценарий 2. Ручной выбор аудиторий

Шаги:

1. Открыть ручной режим.
2. Выбрать одну или несколько аудиторий.
3. Заполнить время и описание.
4. Нажать `Применить`.

Ожидаемый результат:

- окно достаточно широкое;
- текст времени и описания виден;
- выбранные аудитории попадают в список запуска.

### Сценарий 3. Запуск трансляций

Шаги:

1. Подтвердить выбранные аудитории.
2. Запустить трансляции.

Ожидаемый результат:

- открываются отдельные окна трансляций;
- открывается окно уведомлений;
- окна размещаются без длительного подвисания;
- на окнах трансляций есть кнопка обновления.

### Сценарий 4. Полуавтомат записи

Шаги:

1. Нажать `Запись` в окне уведомлений.
2. В VK Call вручную открыть шестеренку и пункт `Записать звонок`.
3. Дождаться появления диалога `Создать запись звонка`.

Ожидаемый результат:

- приложение показывает подсказку оператору;
- после появления диалога название заполняется автоматически;
- название имеет формат `В-503А 04_06_2026`;
- программа нажимает кнопку `Записать звонок`;
- результат появляется в журнале уведомлений.

### Сценарий 5. Автозапись

Шаги:

1. Включить `Авто`.
2. Указать время.
3. Нажать `OK`.

Ожидаемый результат:

- спинбоксы не слипаются с кнопками;
- время можно ввести вручную;
- если время уже прошло, появляется сообщение о недействительном интервале;
- если время актуально, постановка записи планируется.

### Сценарий 6. EXE-сборка

Шаги:

1. Выполнить `powershell -ExecutionPolicy Bypass -File build_exe.ps1`.
2. Запустить `dist/TranslaziaFDO/TranslaziaFDO.exe`.

Ожидаемый результат:

- EXE собирается без ошибок;
- приложение стартует;
- данные, настройки и vendor-модули доступны из frozen-режима.
