# Prompt v006 - Фирменный стиль ФДО

## Причина изменения

Пользователь предоставил логотип факультета и попросил сделать его логотипом и иконкой приложения. Визуальный стиль должен быть ближе к гармонии белого и синего цветов, как на фирменных изображениях ФДО.

## Requirements

- Использовать предоставленный синий логотип ФДО как основной логотип приложения.
- Сформировать иконку приложения для окна, панели задач и tray.
- Добавить логотип в шапку главного окна.
- Добавить логотип в окно уведомлений.
- Перевести UI с зелено-серой схемы на бело-синюю палитру.
- Сохранить практичный, рабочий интерфейс без декоративного перегруза.
- Добавить тест наличия бренд-ассетов.

## Entities

- `logo_fdo.png`
- `logo_fdo.ico`
- `app_icon`
- brand header
- blue-white stylesheet

## Approach

Создать папку `translazia_client/assets`, положить туда логотип и производные размеры. Подключить иконку через `QApplication.setWindowIcon`, `MainWindow.setWindowIcon` и `QSystemTrayIcon`. Обновить stylesheet: основной фон светлый, заголовочная зона синяя, карточки белые, таблицы с голубыми заголовками.

## Structure

```text
translazia_client/assets/
translazia_client/resources.py
translazia_client/ui/styles.py
translazia_client/views/main_window.py
translazia_client/views/notification_window.py
```

## Operations

1. Создать PNG и ICO ассеты из предоставленного логотипа.
2. Добавить `resources.py`.
3. Подключить `app_icon()` в `app.py`.
4. Добавить логотип в brand header главного окна.
5. Добавить логотип в окно уведомлений.
6. Переписать палитру stylesheet.
7. Добавить тест наличия ассетов.

## Norms

- Белый и синий - основные цвета.
- Акценты должны быть читаемыми на светлом и синем фоне.
- В рабочих таблицах сохранить плотность и сканируемость.

## Safeguards

- Не ломать MVC-разделение.
- Не встраивать абсолютные пути к Downloads в код.
- Не делать интерфейс похожим на лендинг: это рабочее приложение.
