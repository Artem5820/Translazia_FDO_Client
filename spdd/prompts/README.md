# Версионируемые SPDD-промпты

Эта папка содержит отдельные версии структурированных промптов, использованных при доработке Translazia FDO. Каждый файл фиксирует цель итерации, контекст, ограничения, ожидаемые изменения в коде и проверки.

Порядок применения:

1. Сначала уточняется требование.
2. Затем создается или обновляется prompt-файл.
3. После этого вносятся изменения в код.
4. В конце обновляются тесты и `spdd/verification.md`.

Так промпты становятся частью проекта и могут проверяться вместе с кодом.
