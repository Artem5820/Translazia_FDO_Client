# Prompt 008 - Полуавтомат записи и EXE-сборка

## Цель

Доработать механизм постановки записи звонка и подготовить приложение Translazia FDO к запуску через EXE-файл.

## Контекст

Полностью автоматический поиск шестеренки VK и координатные клики работают нестабильно: окно может быть свернуто, VK Call может быть не полностью загружен, а интерфейс VK меняет расположение элементов. Из-за этого автоматизация нажимает не на те элементы.

## Требования

- Не выполнять хаотичные клики по координатам.
- Оставить QWebEngineView как основной механизм отображения VK Call.
- Реализовать полуавтомат:
  - программа открывает окна трансляций;
  - оператор вручную нажимает шестеренку и пункт `Записать звонок`;
  - когда появляется диалог `Создать запись звонка`, программа сама заполняет название;
  - название формируется как `Аудитория ДД_ММ_ГГГГ`;
  - программа нажимает кнопку `Записать звонок`.
- Добавить понятные уведомления о статусе: ожидание диалога, успешная команда, таймаут, занятие не началось.
- Подготовить PyInstaller-сборку:
  - добавить `.spec`;
  - добавить `build_exe.ps1`;
  - обеспечить работу путей в frozen-режиме;
  - включить `data`, настройки и vendor-модули.

## Подход

Использовать JavaScript внутри QWebEngineView только для поиска уже открытого диалога записи и заполнения его полей. Не искать шестеренку и не нажимать по координатам. Для EXE-сборки использовать PyInstaller, а в `config.py` различать исходный и frozen-режим.

## Проверки

- Unit-тесты проходят.
- `compileall` проходит.
- EXE собирается.
- EXE запускается smoke-test запуском.
- В уведомлениях отображается, что запись работает в полуавтоматическом режиме.

## Ограничения

Если оператор не открыл диалог записи, программа не должна пытаться нажимать случайные элементы. Она должна показать таймаут и инструкцию.
