# Prompt v004 - Операционная доработка клиента

## Причина изменения

После MVC-рефакторинга клиент соответствует базовой структуре, но для ежедневной работы по ТЗ нужны дополнительные эксплуатационные улучшения: явное подтверждение аудиторий перед запуском, быстрый выбор аудиторий, проверка готовности зависимостей и точная работа со временем запуска по Москве.

## Requirements

- Добавить финальный диалог проверки аудиторий перед запуском окон.
- В диалоге оператор должен иметь возможность снять аудиторию, если занятие отменено.
- Добавить быстрые кнопки `Все`, `Ничего`, `Инвертировать` и счетчик выбранных аудиторий.
- Вести счетчики событий, ошибок и находок нейросетей в окне уведомлений.
- Подсвечивать строки журнала анализа по уровню: ошибка, проблема, норма.
- Считать время автозапуска явно в часовом поясе `Europe/Moscow`.
- На старте выполнять healthcheck зависимостей, seed-файла и нейросетевых весов.

## Entities

- `LaunchReviewDialog`
- `HealthIssue`
- `run_startup_healthcheck`
- `now_moscow`
- `parse_hhmm`
- selection counter
- notification counters

## Approach

Добавить небольшие сервисы и отдельный view, не нарушая MVC:

- `services/time_service.py` отвечает за московское время;
- `services/healthcheck.py` проверяет готовность окружения;
- `views/launch_review_dialog.py` отвечает только за финальную проверку аудиторий;
- `MainController` связывает новые элементы со сценарием запуска.

## Structure

```text
translazia_client/
  services/healthcheck.py
  services/time_service.py
  views/launch_review_dialog.py
  views/main_window.py
  views/notification_window.py
  controllers/main_controller.py
```

## Operations

1. Добавить сервис московского времени.
2. Заменить локальный `datetime.now()` в планировщике на `now_moscow()`.
3. Добавить healthcheck на старте клиента.
4. Добавить кнопки управления выбором аудиторий.
5. Добавить финальный диалог подтверждения запуска.
6. Добавить счетчики и цветовую индикацию уведомлений/журнала.
7. Расширить тесты.

## Norms

- Диалог запуска не должен открывать окна сам, он только возвращает выбранные аудитории.
- Healthcheck не должен падать исключением; проблемы показываются оператору.
- Вся эксплуатационная информация должна попадать в окно уведомлений.
- Тесты не должны открывать реальные VK Call окна.

## Safeguards

- Если пользователь отменил запуск или снял все галочки, трансляции не открываются.
- Если зависимости не найдены, ошибка видна в UI.
- Автозапуск не должен зависеть от локальной системной зоны, только от `Europe/Moscow`.
