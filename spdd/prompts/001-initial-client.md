# Prompt v001 - Базовый клиент трансляций

## Контекст

Есть существующее приложение расписания, но его переделывать нельзя. Нужно создать отдельный desktop-клиент для вечерних трансляций ФДО.

## Требования

- считать список аудиторий и VK Call ссылок из файла `Podklyuchenie_k_translyatsiam_FDO.txt`;
- показать все аудитории с чекбоксами;
- по умолчанию выбрать все аудитории;
- открыть выбранные трансляции в отдельных окнах;
- равномерно разложить окна по доступному экранному пространству;
- поддержать несколько мониторов;
- добавить настройки интервала и длительности проверок;
- подключить готовые модули `vk_video_analyzer` и `SoundChecker`.

## Ограничения

- старое приложение не менять;
- использовать локальный проект `Translazia_FDO`;
- код должен запускаться на Windows;
- зависимости фиксировать в `requirements.txt`.

## Ожидаемый результат

Рабочий прототип клиента с GUI, чтением seed-файла, запуском окон и подключенным видеоанализатором.
