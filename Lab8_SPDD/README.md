# Лабораторная работа №8

В данной папке собраны материалы по лабораторной работе на тему разработки на основе структурированных промптов (Structured-Prompt-Driven Development, SPDD). Материалы вынесены отдельно, чтобы не смешивать их с исходным кодом основного проекта.

Состав папки:

- [report.md](C:/Module_video_analys/lab8_spdd/report.md) — основной текст отчета по лабораторной работе
- [test_scenarios.md](C:/Module_video_analys/lab8_spdd/test_scenarios.md) — тестовые сценарии, составленные на основе требований к модулю
- [prompts/prompt_v1.md](C:/Module_video_analys/lab8_spdd/prompts/prompt_v1.md) — первая версия структурированного промпта

Доработка модуля анализа учебных видеотрансляций в рамках курсового проекта с использованием методологии SPDD.
