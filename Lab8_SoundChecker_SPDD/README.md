# Лабораторная работа №8

В данной папке собраны материалы по лабораторной работе на тему разработки на основе структурированных промптов (Structured-Prompt-Driven Development, SPDD).

Тема работы: разработка аудиомодуля SoundChecker для анализа звуковой дорожки учебной трансляции.

Состав папки:

- [report.md](report.md) — основной отчет по лабораторной работе;
- [test_scenarios.md](test_scenarios.md) — тестовые сценарии для проверки модуля;
- [prompts/prompts.md](prompts/prompts.md) — версии структурированных промптов;
- [lab8.docx](lab8.docx) — версия отчета в формате Word.

Основные файлы проекта, на которые опирается лабораторная работа:

- [../soundchecker/audio.py](../soundchecker/audio.py);
- [../soundchecker/analyzer.py](../soundchecker/analyzer.py);
- [../soundchecker/cli.py](../soundchecker/cli.py);
- [../soundchecker/spectrogram.py](../soundchecker/spectrogram.py);
- [../requirements.txt](../requirements.txt);
- [../requirements-vad.txt](../requirements-vad.txt).
