# Тестовые сценарии

В документе приведены тестовые сценарии для функциональной проверки аудиомодуля SoundChecker.

| № | Сценарий | Входные данные | Команда | Ожидаемый результат |
|---|---|---|---|---|
| 1 | Нормальная речь | `тестречь.mp3` | `python -m soundchecker .\тестречь.mp3` | JSON со значением `"статус": "ok"`, список `"проблемы"` пуст |
| 2 | Почти полная тишина | `тесттишина.mp3` | `python -m soundchecker .\тесттишина.mp3` | JSON со значением `"статус": "critical"`, проблемы `no_speech`, `mostly_silence`, `low_volume` |
| 3 | Русский вывод по умолчанию | `тестречь.mp3` | `python -m soundchecker .\тестречь.mp3` | В JSON есть ключи `"статус"`, `"метрики"`, `"пороги"` |
| 4 | Технический английский вывод | `тестречь.mp3` | `python -m soundchecker .\тестречь.mp3 --english-keys` | В JSON есть ключи `status`, `metrics`, `thresholds` |
| 5 | Сохранение спектрограммы | `тестречь.mp3` | `python -m soundchecker .\тестречь.mp3 --spectrogram .\speech.png` | Создается файл `speech.png`, в JSON появляется блок артефактов |
| 6 | Несуществующий файл | `missing.mp3` | `python -m soundchecker .\missing.mp3` | JSON со статусом ошибки загрузки аудио |
| 7 | Тихая речь | тихий аудиофрагмент | `python -m soundchecker .\quiet.mp3` | Статус `warning`, проблема `low_volume` |
| 8 | Перегруженный сигнал | файл с клиппингом | `python -m soundchecker .\clipped.wav` | Статус `warning`, проблема `clipping` |
| 9 | Высокочастотный шум | файл с шипением | `python -m soundchecker .\noise.wav` | Проблема `high_frequency_noise` при превышении порога |
| 10 | Низкочастотный гул | файл с гулом 50/60 Гц | `python -m soundchecker .\hum.wav` | Проблема `power_hum` при превышении порога |

## Фактически выполненная проверка

Для проверки использовались два файла из корня проекта:

– `тестречь.mp3`;

– `тесттишина.mp3`.

Результат для `тестречь.mp3`:

```json
{
  "статус": "ok",
  "сообщение_статуса": "Проблем со звуком не обнаружено",
  "проблемы": [],
  "метрики": {
    "длительность_сек": 73.105,
    "частота_дискретизации_гц": 16000,
    "средняя_громкость_dbfs": -29.02,
    "пиковая_громкость_dbfs": -3.56,
    "доля_тишины": 0.3251,
    "доля_речи": 0.9215,
    "доля_перегруза": 0.0,
    "оценка_snr_db": 52.1
  }
}
```

Результат для `тесттишина.mp3`:

```json
{
  "статус": "critical",
  "сообщение_статуса": "Обнаружена критическая проблема со звуком",
  "проблемы": [
    {
      "код": "no_speech",
      "важность": "critical",
      "сообщение": "Речь не обнаружена"
    },
    {
      "код": "mostly_silence",
      "важность": "critical",
      "сообщение": "Аудио почти полностью состоит из тишины"
    },
    {
      "код": "low_volume",
      "важность": "warning",
      "сообщение": "Слишком низкая громкость"
    }
  ]
}
```

Вывод: модуль корректно различает нормальную речь и почти полную тишину.
